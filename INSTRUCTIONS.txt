# 📥 Project: yotu-bo (Vision-Based YT Uploader)

## 📌 Project Overview
"yotu-bo" is a desktop automation tool built with Python. It uses PyQt6 for the user interface and PyAutoGUI for vision-based automation. The goal is to automate video uploads to YouTube by mimicking human mouse clicks and keyboard inputs, utilizing existing Google Chrome profiles to bypass API quota restrictions.
